## 🌐 What Is OpenFPV\_Pilot?

**OpenFPV\_Pilot** is a free, open-source, end-to-end drone education platform covering every dimension of unmanned vehicle operation — from reading your first sim telemetry to flying a long-range agricultural mission or mapping a 3D terrain.

We don't stop at flying. We teach you to **build, repair, simulate, model, 3D visualize, troubleshoot, and source parts** for every class of unmanned vehicle — air, water, underground, and land.

> **Our promise:** You will go from zero knowledge → certified simulation pilot → real-world flight-ready in a structured, hands-on curriculum backed by an interactive 3D model library, animated lessons, and a global vendor ecosystem.

## 🎮 Simulation Track

> **Start here if you've never flown.** Real hardware is expensive. Crashes are free in a sim.

### Why Simulation First?

Muscle memory built in a simulator transfers directly to real aircraft. Our simulation curriculum is mapped 1:1 to real-world skill benchmarks — every lesson gate in the sim corresponds to a verified real-world milestone.


### Sim Curriculum — Structured Progression

```
LEVEL 0  ── Controller familiarization (modes, sticks, switches)
LEVEL 1  ── Hover stability (position hold ON → OFF)
LEVEL 2  ── Basic maneuvers (yaw, pitch, roll, altitude)
LEVEL 3  ── Figure-8, orbits, box patterns
LEVEL 4  ── Manual mode — full acro (no stabilization)
LEVEL 5  ── FPV only — camera-only navigation
LEVEL 6  ── Racing gates and obstacle courses
LEVEL 7  ── Long-range waypoint mission simulation
LEVEL 8  ── Emergency procedures (motor-out, failsafe, RTL)
LEVEL 9  ── Mapping mission planning and execution
LEVEL 10 ── Real-world flight certification readiness
```

## 🛠 Repair & Troubleshooting

A full diagnostic tree for every failure mode — from blown ESCs to GPS glitches.

### Troubleshooting Trees

```
SYMPTOM: Won't arm
  ├── Check: Failsafe active? → Rebind receiver
  ├── Check: Gyro calibration fail? → Level FC, recalibrate
  ├── Check: RPM filter enabled but no DSHOT telemetry? → Enable bidirectional DSHOT
  └── Check: Arming angle too steep? → Set arming_angle in CLI

SYMPTOM: Motors twitching at idle
  ├── Check: ESC desync → Lower timing, update BLHeli_32 firmware
  ├── Check: Ground loop → Star-ground all ESC signal wires
  └── Check: Capacitor missing → Add 1000µF low-ESR cap to battery lead

SYMPTOM: Video feed noise / sparkling
  ├── Check: VTX power supply dirty → Add LC filter
  ├── Check: Antenna SWR → Replace or reposition antenna
  └── Check: VTX overheating → Check power output, add airflow

SYMPTOM: GPS not locking
  ├── Check: Compass interference → Move GPS mast higher
  ├── Check: Metal frame shielding → Use active antenna or reposition
  └── Check: Bad satellite geometry → Wait or move to open sky

SYMPTOM: Fly-away / toilet bowl effect
  ├── Check: Compass not calibrated → Redo outdoor compass cal
  ├── Check: Declination wrong → Set mag_declination in CLI
  └── Check: Compass orientation → Verify align_mag in Betaflight/iNav
```

### Repair Modules

- **Motor repair** — Bearing replacement, stator cleaning, rewind basics
- **FC repair** — SMD pad reflowing, USB port repair, burnt trace bypass
- **ESC repair** — FET replacement, bootstrap capacitor, gate resistor
- **Frame repair** — Carbon fiber crack assessment, arm replacement, resin fill
- **Battery repair** — Cell balance recovery, storage charge, puncture assessment
- **Camera/VTX** — Lens replacement, ribbon cable, power isolation

## 📐 Metrics & Telemetry

### Key Flight Metrics

| Metric | What It Tells You | Where to Read It |
|---|---|---|
| **Motor temps** | Thermal stress, prop/PID efficiency | Post-flight hand-check / telemetry |
| **Throttle %** | Headroom remaining, efficiency | Betaflight OSD, Blackbox |
| **Gyro noise** | Mechanical vibration, filter effectiveness | Blackbox Explorer |
| **PID error** | Tune quality (P, I, D balance) | Blackbox PID debug |
| **Battery IR** | Cell health, age, temperature | Charger, battery analyzer |
| **RSSI / LQ** | Link quality (ELRS = LQ, CRSF dBm) | OSD, transmitter |
| **GPS HDOP** | Positional accuracy quality | OSD, Mission Planner |
| **Current draw** | Power budget, battery sizing | Current sensor on OSD |
| **Blackbox rate** | Log resolution (debug vs full capture) | Betaflight Configurator |
| **VBAT sag** | Battery health under load | Blackbox, OSD alerts |

### Blackbox Analysis Workflow

```
1. Arm with Blackbox logging enabled (DSHOT telemetry recommended)
2. Fly a test pack — hover, punch-out, yaw spins
3. Download .BBL via Betaflight Configurator
4. Open in Blackbox Explorer
5. Analyze:
   ├── Gyro vs PID setpoint — look for P oscillation spikes
   ├── Motor outputs — check for motor imbalance
   ├── Step response — evaluate D-term delay
   └── Throttle vs temps — check for thermal throttling
6. Tune PIDs based on analysis
7. Repeat
```
